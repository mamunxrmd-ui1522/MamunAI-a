# Mamun AI Android Starter
এটি সোর্স কোডের ZIP, APK নয়। এতে প্রাথমিক অ্যাপ স্ক্রিন ও ভাসমান WAIT ডেমো প্যানেল আছে।
এখনো Quotex চার্ট বিশ্লেষণ, লাইভ ডেটা বা UP/DOWN সিগন্যাল নেই। ট্রেডিং সিগন্যাল নিশ্চিত নয়।
GitHub-এ ZIP আপলোডের পর build করতে ZIP extract করে ভেতরের ফাইলগুলো repository root-এ নিতে হবে, তারপর Android SDK/Gradle দিয়ে build করতে হবে।
